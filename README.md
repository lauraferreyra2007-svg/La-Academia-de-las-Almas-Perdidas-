📖 Descripción del Sitio

**La Academia de las Almas Perdidas** es un sitio web temático de fantasía oscura que presenta una historia original sobre una escuela de magia llamada **Noctiluna**. En este mundo, cada estudiante recibe una criatura mágica como compañera eterna, pero algo oscuro despertó bajo los cimientos del castillo y está robando las almas de las criaturas.

El sitio incluye:
-Inicio: Presentación de la academia y los cuatro pilares de la magia
-Historia: Prólogo y capítulos de la historia completa
-Personajes: Estudiantes y profesores de la academia
-Criaturas: Las criaturas mágicas y el Devorador de Luz
-Contacto: Formulario funcional para enviar mensajes

🎯 Objetivo del Sitio

El objetivo principal es narrar una historia de fantasía de manera inmersiva, utilizando recursos web modernos para crear una experiencia visual y emocional atractiva. El sitio busca:

1.Entretener a los visitantes con una historia original de magia y misterio
2.Demostrar habilidades técnicas en desarrollo web (HTML5, CSS3, JavaScript)
3.Practicar el uso de herramientas modernas como Git, GitHub 
4.Experimentar con diseño responsivo, animaciones y efectos visuales
